# Strefa Przejścia — media do publikacji w social media (strefaprzejscia.pl)

Publiczny hosting grafik i filmów dla postów planowanych w Bufferze (API Buffera przyjmuje media tylko jako URL).

- Adres: `https://devpartner150.github.io/strefa-przejscia-media/social/<plik>`
- Nazwy plików: `RRRR-MM-DD_<id>.<ext>` (data pierwszej publikacji), np. `2026-11-19_g01.jpg`
- Limit GitHuba: 100 MB na plik — filmy kompresować poniżej 50 MB
- Po publikacji posta na wszystkich kanałach jego media można usunąć z repo
